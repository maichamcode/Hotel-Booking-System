# Hotel Booking System

A Hotel Booking System built with Java Spring Boot and Microservice Architecture.

## Tech Stack

- Java 21
- Spring Boot
- Spring Cloud
- Docker
- PostgreSQL
- Redis
- Kafka

## Architecture

- API Gateway
- Discovery Service
- Config Server
- Auth Service
- Hotel Service
- Room Service
- Booking Service
- Payment Service
- Notification Service

## Project Phases

- ✅ Phase 1: Infrastructure
- ⏳ Phase 2: Authentication
- ⏳ Phase 3: Hotel & Room
- ⏳ Phase 4: Booking
- ⏳ Phase 5: Payment

## Run

```bash
docker compose up -d
```
